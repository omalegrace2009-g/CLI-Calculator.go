# CLI-Calculator.go

##  GRACE Calculative World
Welcome to GRACE Calculative World, a simple and interactive command-line calculator built using Go (Golang). This tool allows users to perform basic arithmetic operations through an easy-to-use menu interface.

##  Features

* Addition: Sum two numbers.
* Subtraction: Find the difference between two numbers.
* Multiplication: Multiply two numbers.
* Division: Divide two numbers (includes safety check for division by zero).
* Error Handling: Detects invalid inputs (like letters instead of numbers) and allows you to try again.
* Help Menu: Clear instructions on how to use the application. [3] 

## How to Run

   1. Install Go: Ensure you have Go installed on your machine. You can download it at golang.org.
   2. Save the file: Save the code as main.go.
   3. Execute: Open your terminal or command prompt and run:
   
   go run main.go
   
   
##  Usage
Once the program is running, follow the on-screen prompts:

   1. Choose an operation by typing add, sub, mul, div, or help.
   2. Enter the first number and press Enter.
   3. Enter the second number and press Enter.
   4. The result will be displayed instantly!
   5. Type exit to close the application.
